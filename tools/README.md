# 采集端与服务器维护工具索引

`tools/` 可按用途拆分复制，但不要把真实 Token、数据集或本地配置提交到 Git。

| 目录 | 用途 |
| --- | --- |
| `collector_v1/` | 旧版：人工指定并上传一个完整 LeRobot v3 ZIP |
| `auto_update/` | 第二版：运行一次，扫描文件夹/ZIP，依次上传并退出 |
| `server/` | 平台服务器维护脚本，不复制到机器人设备 |

日常采集推荐使用 `auto_update/`。它不是后台服务，不会持续监控目录；采集完成后由
操作人员或采集程序调用一次。详见 `auto_update/README.md`。
