## 2. 本轮纳入验收的真实功能

- 用户名和密码登录、退出、服务端 Cookie 会话及全站访问保护；
- LeRobot v3 ZIP 单个上传、批量包装接口、安全解压、Raw 入库和 DS 编号登记；
- 数据集登记、列表、详情、重新扫描、视频访问、质检状态和报告回收站；
- Episode/task/Subtask 标注以及完整 Derived 数据集发布；
- Episode 筛除、拆分、合并、重排、精确去重和视频画面裁剪；
- Doctor、机器人规则、VLM 接口框架、质检任务、报告和人工审核；
- 独立机器人档案和数据定义受控词表；
- Docker 默认本机模式、开发模式和可信局域网模式。

## 8. 当前已知限制

- 标注发布和部分处理任务仍在 Web 进程中执行；容器重启时不能续跑；
- 视频处理会重新编码，耗时和磁盘占用随数据规模增加；
- 精确重复检测基于 frame Parquet，不判断视频视觉近似；
- 当前没有 HTTPS、角色权限、登录限速或机器人 API Token，只能用于可信内网；
- 真实 VLM 端到端验收和正式服务器验收尚未执行；
- 正式生产镜像将在下一次代码合并完成后统一重建。
