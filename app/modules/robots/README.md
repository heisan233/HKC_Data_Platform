# 机器人管理

机器人管理维护平台档案和数据集归属，不连接或控制真实机器人。

## 档案

- 稳定编号：`RB000001`；
- 字段：SN、名称、类型、IP 地址、备注和状态；
- 支持新增、编辑、搜索、停用和恢复；
- 不提供永久删除机器人；
- 停用机器人不能接收新 DS 关联或机器上传。

## 数据集关联

- 一台机器人可关联多个 DS；
- 一个 DS 最多关联一台机器人；
- 支持关联、改绑和解除；
- 类型不一致允许人工关联，但页面必须醒目告警；
- 派生 DS 只有在所有来源属于同一机器人时继承；
- DS 移入回收站后仍在机器人页显示并标记“回收站”；
- 永久清除 DS 后才移除关联。

关系只保存在 MySQL，不回写数据集 `info.json`。

## 采集 Token

- 新建机器人时自动生成 Token，成功弹窗显示一次完整值；
- 网页列表和普通接口只返回状态与前缀；
- 网页可重新生成，旧 Token 立即失效；
- 终端 CLI 可查看、补充生成、删除或重新生成；
- 内部部署为便于运维，MySQL 保留可供 CLI 查看完整值；不得把值写入 Git；
- 停用机器人后 Token 认证立即失败。

服务端采集逻辑见 `app/modules/collector/README.md`。
